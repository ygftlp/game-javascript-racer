# Sprint A 稳定可玩版本进度

日期：2026-07-10  
分支：`codex/modularize-v4-racer`

## 本轮已完成

### 1. 微信 Canvas 兼容

- 新增 `RacerCanvasCompat.ts`。
- 游戏启动时安装 `roundRect` 兼容实现。
- 道具状态提示已改用手写圆角路径，不再依赖原生 `ctx.roundRect()`。

### 2. 双指操控稳定性

- 触摸结束事件区分仍按住的触点和刚抬起的触点。
- 屏幕上仍有触点时，输入层重新派发移动状态，而不是重置全部控制。
- 摇杆锁定启动它的 touch id，避免刹车手指抢占方向控制。
- 支持摇杆与刹车按不同顺序抬起。

### 3. 低帧率物理与碰撞

- 游戏状态使用最大 `1 / 60` 秒物理子步进。
- 单帧最大处理时间限制为 0.15 秒。
- 车辆、路边物体和道具碰撞改为使用移动后的 segment。
- 交通和路边碰撞增加冷却判断，避免同一帧或连续子步重复计数。

### 4. 道具公平生成

- 道具数量按赛道长度控制在合理范围。
- 起步安全区不生成早期惩罚组合。
- 氮气和减速陷阱避开过急弯道。
- 减速陷阱之间保持更大间距。
- 同一个 segment 只生成一个道具，保留其他可通行车道。
- 初始交通车会避开同 segment 的道具位置。

### 5. 道具视觉语义

- 加速改为黄色前进箭头符号。
- 氮气保持蓝色 `N` 能量标识。
- 减速物改为红黑地面危险区，不再使用奖励方块外形。

### 6. 自动质量门禁

新增：

```text
scripts/validate-sprint-a.mjs
```

校验范围：

- Canvas 兼容安装。
- 双指触控生命周期。
- 摇杆 touch id 所有权。
- 60Hz 物理子步进。
- 道具安全生成规则。
- 危险物视觉实现。
- 禁止 `Pseudo3DRenderer` 重新使用原生 `ctx.roundRect()`。

该校验已经接入：

```text
npm run validate
npm run build:wx
npm run build:wx:gamex
```
