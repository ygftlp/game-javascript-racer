# Agent D: Audio Replacement

## Mission

Replace legacy music and add optional sound effects with commercial-safe audio that works well in WeChat.

## Owns

- `assets/packs/default/audio/music/`
- `assets/packs/default/audio/sfx/`

## Immediate tasks

1. Produce commercial-safe `assets/packs/default/audio/music/racer.mp3`.
2. Produce optional `assets/packs/default/audio/sfx/engine-loop.mp3`.
3. Produce optional `assets/packs/default/audio/sfx/crash.mp3`.
4. Produce optional `assets/packs/default/audio/sfx/menu-confirm.mp3`.
5. Keep files small enough for WeChat package-size limits.
6. Validate playback after first user interaction.

## Done when

- Background music plays after race start.
- Music pauses and resumes with the game.
- Optional SFX are ready for runtime integration.
- Commercial usage rights are documented outside runtime source.
