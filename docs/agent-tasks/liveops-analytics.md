# Agent: LiveOps & Analytics

## Mission

Make the commercial launch measurable and prepare the first post-launch update loop.

## Responsibilities

- Define analytics event checklist.
- Define KPI review cadence.
- Track retention and replay behavior.
- Track leaderboard and share behavior.
- Plan lightweight liveops updates after launch.

## Current priorities

1. Confirm events exist for race start, race finish, restart, track select, settings changes, share tap, leaderboard tap, and collisions.
2. Define soft-launch KPI dashboard requirements.
3. Define first four-week content/update plan.
4. Track control preset usage and per-track completion.
5. Track ad impact only after monetization is enabled.

## Inputs

- `docs/commercialization-plan.md`
- `docs/commercialization-roadmap.md`
- `docs/open-data-leaderboard-protocol.md`
- `src/scenes/RacerScene.ts`
- `src/racer/RacerWechatServices.ts`

## Deliverables

- Analytics event catalog.
- Soft-launch KPI review template.
- First four-week liveops plan.
- Post-launch tuning recommendations.

## Acceptance criteria

- First race start rate can be measured.
- First race completion rate can be measured.
- Second race start rate can be measured.
- Share and leaderboard taps can be measured.
- Per-track performance can be reviewed separately.
